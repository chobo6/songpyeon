# 한 계정 동시 다중 참가 방지 — 설계 문서

## 배경

같은 계정으로 탭 두 개(또는 기기 두 개)를 열어 같은 매치에 동시에 플레이어로
들어가면, 턴 성공 시 지급되는 게임머니를 실질적으로 두 배로 받을 수 있다.
`MatchRoom.ts`의 `onAuth`는 세션 쿠키로 계정을 인증해 `userId`를 돌려주지만,
`onJoin`이 새 플레이어 자리를 배정할 때 그 `userId`가 이미 이 방의 다른 자리를
차지하고 있는지 확인하지 않기 때문이다. `creditTurnSuccess`는 턴이 성공할 때마다
그 팀의 돼지/토끼 두 자리 각각의 `userId`에 보상을 지급하는데, 두 자리(또는
서로 다른 팀의 두 자리)가 같은 계정이면 같은 계정이 두 번 받게 된다.

## 설계

`onJoin`의 플레이어 배정 분기 — `this.state.players.size >= this.playerCapacity`
(방이 꽉 찼는지) 확인 직후, `const isHost = ...`보다 앞 — 에 새 체크를 추가한다.
`client.auth.userId`가 `this.playerUserIds`(세션ID→유저ID 맵, 이미 존재하며
`creditTurnSuccess` 등에서 재사용 중)의 값 중 하나와 같으면 아래처럼 거부한다:

```ts
const userId = client.auth?.userId;
if (userId !== undefined && [...this.playerUserIds.values()].includes(userId)) {
  throw new Error("이미 이 방에 참가 중인 계정입니다.");
}
```

`playerCapacity`는 팀 수 × 2로 커봐야 한 자릿수라, 배열로 매번 순회해도 성능
문제가 없다 — Set으로 따로 관리할 필요는 없다.

**관전은 막지 않는다.** 이미 플레이어로 들어간 계정이 다른 탭으로 같은 방을
구경만 하는 건 돈을 더 버는 게 아니라 악용이 아니고, `onJoin`의 관전자 분기는
`playerUserIds`를 아예 건드리지 않으므로(관전자는 `state.spectators`에만 들어감)
이 체크는 관전 시도에는 자연스럽게 관여하지 않는다. 그래서 이 체크는 플레이어
배정 분기 안에만 넣고, 관전자 분기(`onJoin` 앞부분)에는 넣지 않는다.

**정상적인 재접속은 영향 없다.** Colyseus의 재접속(`allowReconnection`)은
`onAuth`/`onJoin`을 다시 거치지 않고 기존 세션의 `auth`를 그대로 재사용하는
완전히 별개의 경로다(`MatchRoom.ts`의 `onLeave` 재접속 분기 참고). 그래서 이
체크에 걸리는 건 진짜로 새 연결이 기존 플레이어 자리와 같은 계정으로 들어오려는
경우뿐이며, 새로고침이나 네트워크 끊김 후 정상 재접속은 이 경로를 아예 타지
않는다.

## 테스트

`server/src/rooms/MatchRoom.test.ts`에 새 테스트 추가 — 기존 `connectAsUser`
헬퍼는 호출할 때마다 새 계정을 만들기 때문에 쓸 수 없고, 파일 하단
"user ban" describe 블록의 수동 연결 패턴(같은 `signSession(user.id)` 토큰으로
`ColyseusJsClient`를 직접 만들어 연결)을 그대로 따라 같은 토큰으로 두 번째
연결을 시도한다:

- 같은 계정(같은 `userId`, 같은 세션 토큰)으로 같은 방에 두 번째 플레이어로
  들어가려 하면 거부되는지(`rejects.toThrow()`).
- 서로 다른 계정은 정상적으로 둘 다 플레이어로 들어갈 수 있는지(기존 동작
  회귀 없음 확인 — 이미 `fillRolesAndStart` 등 기존 테스트들이 커버하므로
  새로 추가하지 않아도 됨).
- (선택) 같은 계정이 이미 플레이어로 들어가 있는 상태에서, 매치가 진행 중이라
  같은 계정의 다른 탭이 관전자로는 정상적으로 들어갈 수 있는지 — 관전 분기가
  이 체크와 무관함을 확인하는 회귀 테스트.

## 범위 제외

- 같은 계정이 **서로 다른 방**에 동시에 참가하는 것 — 요청 범위가 "한 게임에"로
  한정되어 있고, 서로 다른 매치는 보상이 서로 독립적이라 다중 참가 자체가
  이득이 되지 않는다.
- 관전자끼리의 중복 참가 제한 — 관전은 애초에 보상이 없어 악용 대상이 아니다.
